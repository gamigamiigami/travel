# Yahoo!トラベル スペシャルクーポン ウォッチャー

Edge と Chrome で Yahoo!トラベルを自動で散策し、**スペシャルクーポン**（1,000 / 2,000 /
3,000 / 5,000 / 50,000円OFF など）が出たらスマホに通知します。

---

## 1. 調べたこと（スペシャルクーポンの仕様）

公式には抽選ロジックが公開されていないため、公開情報からわかった範囲です。

| 項目 | わかっていること |
|---|---|
| 出現の仕方 | サイトにアクセスした瞬間、画面右側などにポップアップで**自動獲得型**として出る |
| 金額 | 1,000円 / 2,000円 / 3,000円 / 5,000円 など。まれに高額枠もある |
| 対象 | 公式が「**対象者の方にのみ表示します**」と明記。**全員が出せるものではない** |
| 有効期限 | ポップアップ表示から **60分 / 90分 / 180分** の時間限定。過ぎると予約途中でも使えない |
| 配布条件 | 配布期間・時間帯・条件はすべて非公開 |
| 出やすいと言われる状況 | ①複数回・数日にわたって訪問している ②1泊5万円クラスの高級宿など、具体的に宿を検索している |

**このツールの設計はこの3点に直結しています。**

- 有効期限が最短60分 → **見逃さないためにリアルタイム通知が要る**（これが本命の価値）
- 「何度も訪れる」→ 一定間隔で繰り返し巡回する
- 「具体的に宿を調べる」→ トップだけでなく**宿の詳細ページまで潜る**
- Edge と Chrome で抽選が別枠の可能性 → **ブラウザごとに別プロファイル**で回す

> ⚠️ 抽選である以上、このツールを動かせば必ず出る、というものではありません。
> 「出たときに確実に気づける」ことが実際の効果です。

## 2. 仕組み

### クーポンの検出（3層で拾う）

DOM構造は非公開で頻繁に変わるため、単一のCSSセレクタには賭けていません。

1. **ネットワーク層** — ページが裏で叩くAPIのJSONレスポンスを覗き、クーポンらしき
   オブジェクトから金額とコードを抜く。見た目が変わっても壊れにくい。
2. **ポップアップ層** — `[role=dialog]` / `[class*=oupon]` / `[class*=odal]` など
   10種類のセレクタを総当たりし、その中のテキストを**ゆるい条件**で判定。
3. **ページ全体層** — body全体のテキストを、「スペシャルクーポン」「クーポンを獲得」
   などの**強いキーワードが金額の近くにあること**を条件に判定。誤検知対策。

検出したら、`data/screenshots/` にスクショ、`data/captures/` にHTMLを保存し、
「クーポンを獲得」ボタンがあれば押した上で通知します。

### 安全装置

- 巡回先は `travel.yahoo.co.jp` 配下のみ。外部サイトには出て行きません
- **予約・決済・購入・キャンセル・アカウント操作系のURLは絶対に踏みません**
  （`crawl.blocked_url_patterns`。消さないでください）
- ボタンを押すのも「クーポン獲得」系の文言だけ。「予約」「決済」「確定」などの語を
  含む要素はクリック対象から除外されます
- 同じクーポンは `detect.dedupe_minutes`（既定180分）の間、再通知しません

## 3. セットアップ（Windows）

### 事前に用意するもの

- **Python 3.11 以上** — [python.org](https://www.python.org/downloads/windows/) から。
  インストール時に「**Add python.exe to PATH**」に必ずチェック
- **Microsoft Edge** と **Google Chrome**（普段お使いのものでOK。追加DLは不要）
- **ntfy アプリ**（通知用）— [Google Play](https://play.google.com/store/apps/details?id=io.heckel.ntfy) / [App Store](https://apps.apple.com/app/ntfy/id1625396347)

### 手順

**① セットアップ**

`setup.bat` をダブルクリック。仮想環境の作成、必要なライブラリの導入、
`config.yaml` の作成まで自動で行い、最後にメモ帳が開きます。

**② 通知先を決める（config.yaml）**

いちばん簡単なのは **ntfy** です。アカウント登録が要りません。

```yaml
notify:
  provider: ntfy
  ntfy:
    topic: "yahoo-coupon-r7k2m9x4qz"   # ← 好きな文字列に変える
```

> 🔑 **トピック名は事実上のパスワードです。** 名前を知っている人は誰でもその通知を
> 読めるので、`yahoo-coupon` のような推測しやすい名前は避け、ランダムな文字を
> 混ぜてください。

スマホの ntfy アプリで「＋」→ 同じトピック名を入力して購読すれば準備完了。

<details>
<summary>メールで受け取りたい場合</summary>

```yaml
notify:
  provider: email
  email:
    smtp_host: smtp.gmail.com
    smtp_port: 465
    username: "あなた@gmail.com"
    password: "アプリパスワード16桁"
    to_addr: "あなた@gmail.com"
```

Gmail は通常のパスワードでは送信できません。Googleアカウントで2段階認証を有効に
した上で「アプリパスワード」を発行してください。なお**メールは配信が数分遅れる
ことがあり、60分限定クーポンでは不利**です。可能なら ntfy を推奨します。
</details>

<details>
<summary>Discord で受け取りたい場合</summary>

サーバー設定 →「連携サービス」→「ウェブフック」で URL を作り、
`notify.provider: discord` と `webhook_url` を設定してください。
スクショがそのまま画像として貼られるので見やすいです。
</details>

**③ 通知テスト**

`test-notify.bat` を実行。スマホに通知が届けばOKです。

**④ 初回ログイン（1回だけ）**

`login.bat` を実行すると Edge → Chrome の順にウィンドウが開きます。

1. 各ウィンドウで Yahoo! JAPAN にログイン
2. 「**ログイン状態を保持する**」はONのままに
3. ログインできたらコンソールで Enter

ログイン情報は `profiles/edge` と `profiles/chrome` に保存されます。
**以降は再ログイン不要**です。普段お使いのブラウザとは別のプロファイルなので、
ツールが動いていても普段の Edge / Chrome はそのまま使えます。

**⑤ 巡回開始**

`run.bat` を実行。あとは放置してください。

## 4. PC起動時に自動で動かす（常駐）

1. `config.yaml` の `crawl.headless` を `true` にする（ウィンドウが出なくなります）
2. タスクスケジューラを開く → 「基本タスクの作成」
3. トリガー：「**ログオン時**」
4. 操作：「プログラムの開始」
   - プログラム： `wscript.exe`
   - 引数： `"C:\パス\travel\run-hidden.vbs"`
   - 開始： `C:\パス\travel`
5. 作成後、タスクのプロパティで「**タスクを実行するためにスリープを解除する**」を
   ONにしておくと取りこぼしが減ります

## 5. 誤検知・未検知を直す

Yahoo!トラベルの画面は変わります。うまく動かないときは:

```bat
:: 実際のページを保存する（クーポンが出た瞬間に Enter を押す）
.venv\Scripts\python -m yahoo_coupon_watcher capture --browser edge

:: 保存したファイルで検出ロジックを試す
.venv\Scripts\python -m yahoo_coupon_watcher scan-file data\captures\20260909-120000_edge.txt
```

- **通知が来すぎる** → `detect.ignore_patterns` にその文言（正規表現）を足す。
  または `detect.amounts_whitelist: [3000, 5000, 50000]` のように金額を絞る
- **クーポンが出たのに通知されない** → `capture` で保存したテキストを見て、
  クーポンの文言が `detector.py` の `STRONG_KEYWORDS` にあるか確認する
- **とりあえず動きを見たい** → `.venv\Scripts\python -m yahoo_coupon_watcher run --once -v`

## 6. 使うときのお願い

- **巡回間隔を短くしないでください。** 既定は12〜25分に1回（1日およそ60〜100回の
  ページ表示）で、人が熱心に宿を探しているのと同程度に収まる設計です。
  これを数十秒間隔にすると相手のサーバーに負担をかけますし、弾かれる可能性も上がります。
- 深夜（既定は1時〜7時）は自動で停止します（`crawl.quiet_hours`）。
- 自分のアカウントで自分の分の抽選を回すための個人用ツールです。複数アカウントの
  併用や、クーポンの転売目的での利用は想定していません。
- Yahoo!トラベルの利用規約・仕様変更により使えなくなる可能性があります。
  自己責任でご利用ください。
